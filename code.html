房间动态

📖 玩法说明
  1. 进房间：所有人点群里的同一个链接，输入名字后选黑方或白方即可入场。
  2. 团队接力：同一方可以有任意多人，谁在线谁来落子；一方落完子，自动轮到另一方。
  3. 落子：点交叉点选中（出现预览子），再点一次同一位置确认。
  4. 悔棋：由刚落子那一方的成员发起，撤回该方最后一手。
  5. 房主：第一个进房的人自动成为房主；房主关掉页面后，其他人会自动接管房间并恢复棋局。
  6. 连不上？：点 QQ 右上角「…」→ 用系统浏览器打开链接再试。
